# นำแอป POS ไปใช้จริงบนมือถือ (หลายเครื่อง ข้อมูลตรงกัน)

โปรเจกต์นี้คือแอป POS เดิมของร้าน แต่แก้ให้เก็บข้อมูลบน **Supabase** (ฟรี ไม่ต้องผูกบัตรเครดิต)
เพื่อให้เปิดจากมือถือกี่เครื่องก็ได้ แล้วเห็นสินค้า/ยอดขายตรงกันหมด

ทำตามลำดับนี้ได้เลย ไม่ต้องเขียนโค้ดเพิ่ม แค่ตั้งค่าและอัปโหลด

---

## ขั้นตอนที่ 1 — สร้างฐานข้อมูล Supabase (ฟรี ไม่ต้องผูกบัตร)

1. เปิด https://supabase.com → กด **Start your project** → สมัคร/ล็อกอินด้วย GitHub (ง่ายสุด ไม่ต้องผูกบัตรเครดิต)
2. กด **New project** → ตั้งชื่อ (เช่น `bakery-pos`)
   - ตั้ง Database Password (กด generate ให้อัตโนมัติก็ได้ แล้วกดคัดลอกเก็บไว้ เผื่อใช้)
   - เลือก Region เป็น **Southeast Asia (Singapore)**
   - กด **Create new project** แล้วรอประมาณ 1-2 นาที
3. เมื่อโปรเจกต์พร้อมแล้ว ไปที่เมนูซ้าย **Table Editor** → กด **New table**
   - ตั้งชื่อตารางว่า `posdata`
   - **ปิด (uncheck) Enable Row Level Security (RLS)** เพื่อความง่าย (ดูคำเตือนด้านล่าง)
   - เพิ่มคอลัมน์:
     - `key` — type `text`, ติ๊ก **Primary Key**
     - `value` — type `text`
   - กด **Save**
4. ไปที่เมนูซ้าย **Project Settings** (ไอคอนเฟือง) → **API**
   - คัดลอกค่า **Project URL**
   - คัดลอกค่า **anon public** (อยู่ในหัวข้อ Project API keys)

## ขั้นตอนที่ 2 — ใส่ค่า Supabase ลงในโปรเจกต์

เปิดไฟล์ `src/supabaseConfig.js` แล้วแทนที่ค่า `PASTE_YOUR_...` ด้วยค่าจริงที่คัดลอกมาจากขั้นตอนที่ 1

```js
export const supabaseUrl = "https://xxxxxxxxxxxx.supabase.co";
export const supabaseAnonKey = "eyJhbGciOi...(ยาวๆ)...";
```

## ขั้นตอนที่ 3 — ทดสอบในคอมก่อน (ไม่บังคับแต่แนะนำ)

ต้องมี Node.js ก่อน (ถ้ายังไม่มี โหลดที่ https://nodejs.org เลือกเวอร์ชัน LTS)

เปิด Terminal / Command Prompt ในโฟลเดอร์นี้ แล้วรัน:
```
npm install
npm run dev
```
จะได้ลิงก์ เช่น `http://localhost:5173` เปิดดูในคอมได้เลย
(อยากลองบนมือถือตอนนี้เลยก็ได้ โดยต่อ wifi เดียวกับคอม แล้วเปิดลิงก์ `Network:` ที่ vite โชว์ให้)

## ขั้นตอนที่ 4 — อัปโหลดขึ้นเน็ต ให้ได้ลิงก์ใช้งานจริง (Vercel)

1. ไปที่ https://github.com → สมัครฟรี → กด **New repository** ตั้งชื่อ เช่น `bakery-pos` → Create
2. ในหน้า repo กด **Add file > Upload files** แล้วลากไฟล์/โฟลเดอร์ทั้งหมดในนี้ขึ้นไป → Commit
3. ไปที่ https://vercel.com → สมัคร/ล็อกอินด้วยบัญชี GitHub เดียวกัน
4. กด **Add New > Project** → เลือก repo `bakery-pos` ที่เพิ่งอัปโหลด → กด **Deploy**
5. รอ 1–2 นาที จะได้ลิงก์ เช่น `https://bakery-pos.vercel.app` — นี่คือแอปจริงของร้านแล้ว

## ขั้นตอนที่ 5 — ติดตั้งเป็น "แอป" บนมือถือ

เปิดลิงก์จากขั้นตอนที่ 4 บนมือถือของพนักงานแต่ละคน (จะกี่เครื่องก็ได้ ข้อมูลจะตรงกันหมดเพราะดึงจาก Supabase เดียวกัน):

- **iPhone (Safari):** กดปุ่มแชร์ (สี่เหลี่ยมมีลูกศรขึ้น) → เลื่อนหา **Add to Home Screen**
- **Android (Chrome):** กดจุดสามจุดมุมขวาบน → **Add to Home screen / Install app**

จะได้ไอคอนแอปบนหน้าจอโฮม เปิดใช้ได้เหมือนแอปทั่วไป โดยไม่ต้องผ่าน App Store / Play Store

---

## ⚠️ เรื่องความปลอดภัยของข้อมูล

การปิด RLS (Row Level Security) ในขั้นตอนที่ 1 หมายความว่า **ใครก็ตามที่รู้ Project URL + anon key จะอ่าน/แก้ข้อมูลได้**
เหมาะกับร้านเล็กที่ใช้ภายในทีมเท่านั้น และ anon key จะไม่ถูกเปิดเผยตรงๆ ในหน้าเว็บ (แต่คนที่จงใจเปิดดูโค้ดเบื้องหลังเว็บก็เห็นได้)

ถ้าต้องการความปลอดภัยขึ้น ทำได้ 2 ทาง (แจ้งได้ถ้าอยากให้ช่วยตั้งค่า):
- เปิด RLS กลับมา แล้วเพิ่ม policy จำกัดสิทธิ์เฉพาะที่ต้องการ
- เพิ่มระบบล็อกอินด้วย Supabase Auth ก่อนเข้าใช้แอป
